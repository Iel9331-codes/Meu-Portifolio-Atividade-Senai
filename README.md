# Portfólio Pessoal & Cantina do Pará Lanches

## Descrição
Este é um projeto de site desenvolvido durante as aulas de Desenvolvimento de Sistemas no SENAI. Ele funciona como meu portfólio pessoal, apresentando uma página inicial sobre mim, um formulário de contato e uma área de projetos com o site da **Cantina do Pará Lanches**, que conta com cardápio em tabela, cardápio completo em PDF, passo a passo de como pedir e links úteis.

---

## Tecnologias Utilizadas
* **HTML5:** Estruturação das páginas, formulários, tabelas, listas, imagens e links.
* **CSS:** Estilização visual com variáveis de cores (`:root`), Box Model, Flexbox, efeitos `:hover` e design responsivo.

---
 
## Como abrir o site
1. Baixe ou copie a pasta completa do projeto para o seu computador.
2. Abra a pasta do projeto e dê dois cliques no arquivo **`index.html`** para abrir direto no navegador.
   * *(Opcional)* Se estiver usando o **VS Code**, clique com o botão direito no `index.html` e selecione **Open with Live Server**.

# O que eu aprendi
* Estruturar páginas web usando tags semânticas do HTML (`header`, `nav`, `main`, `section`, `footer`, `figure`).
* Criar formulários de contato, tabelas de preços, listas e links que abrem arquivos PDF no navegador.
* Construir cartões e alinhar elementos na tela usando **Box Model** e **Flexbox**.
* Adaptar o visual do site para telas menores (celulares de até 600px) usando **Media Queries** (`@media`).
